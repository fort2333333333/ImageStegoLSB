### 项目介绍
将信息藏到图片指定像素的最低位以在图片中藏匿信息。
修改后图片和原图区别非常小，肉眼几乎不可能分辨。

代码会从左上角遍历像素点，如果像素点满足像素选择算法的条件，则会将信息的三个比特分别写入该像素RGB的最低位，并用相同的方法从图片读取信息。
### 注意事项
- 仅支持RGB/RGBA的png
- 图片若不能写入完整数据会截掉写不下的部分，写入后请检查控制台输出
- 对未被写入信息的图片进行读取会读到乱码
- 生成和写入用的不是一套自定义像素选择或加密算法大概率也会读到乱码
- 项目没有提供加密算法，如有需要可以自己写
### 写入图片
- 在`.py`文件同目录下保存`raw.png`作为原始图片
- 在`.py`文件同目录下保存`message.txt`作为待写入的信息
- 运行`write.py`，会自动生成`processed.png`
### 读取信息
- 在`.py`文件同目录下保存`processed.png`作为原始图片
- 运行`read.py`，会自动生成`message.txt`作为读取的信息
### 默认像素选择算法
当像素的x坐标异或y坐标的结果是质数时才会写入，用了缓存优化了判断质数的效率。被选中的像素约占15%，平均17.6像素存1字节。
### 自定义像素选择算法
请修改`selection.py`内的`write()`函数，参数为像素的x坐标`(int)`和y坐标`(int)`，返回值是是否写该像素`(bool)`，并确保写入和读取使用同一套像素选择算法。
### 自定义加密算法
可以修改`selection.py`内的`write_opposite()`，`encrypt()`和`decrypt()`函数来实现加密算法
- `encrypt()`在`write.py`信息写入图片前被调用，会接收`message.txt`内读到的信息`(bytes)`，返回值`(bytes)`会替代原信息被写入到`processed.png`内
- `write_opposite()`会在每次读取或写入图片像素最低位时被调用，参数为像素的x坐标`(int)`和y坐标`(int)`，返回值为写入或读取的最低位比特是否被反转
- `decrypt()`在`read.py`信息写入文本前被调用，decrypt会接收图片内读取到的信息`(bytes)`，返回值`(bytes)`会替代读取到的信息被写入到`message.txt`中
